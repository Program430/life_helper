# Life Helper

Минимальная система для хранения личной информации, мыслей и повседневных дел.

Каждая сущность хранится отдельно и имеет собственную логику работы и поиска.

## Сущности

### Link

Полезные ссылки и ресурсы.

- `url`
- `description`
- `category`

### Thought

Мысли и идеи без срока и даты выполнения.

- `content`
- `category`

### Task

Конкретные дела, которые нужно выполнить.

- `title`
- `description`
- `deadline`
- `status`
- `priority`

### Event

События, привязанные к конкретному времени.

- `title`
- `description`
- `start_at`
- `end_at`
- `location`

Например: запись к стоматологу или встреча.

### Debt

Долги и обязательства.

- `person`
- `amount`
- `currency`
- `description`
- `due_date`
- `status`

## Принципы

- Сущности разделены по своим доменам.
- Поиск сначала выполняется внутри одной сущности.
- Используются только необходимые поля.
- Теги, инструкции, отдельные планы и общий поиск могут быть добавлены позже.
